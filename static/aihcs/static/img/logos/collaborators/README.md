`content/collaboration.yaml`. Each was taken from its owner's own site unless
noted, and is vendored verbatim — the one exception is noted under Harvard
below — so that what the page shows is the mark as its owner publishes it.

Pitt, Emory, UIC, RIT, NTT and Michigan are from Wikimedia rather than the
owner's site. Emory, UIC, RIT and NTT build their masthead mark in a way that
leaves no file to take; Pitt publishes its lockup only reversed out of a dark
background, and Wikipedia's copy is the positive colourway a white card needs;
`umich.edu` sits behind a Cloudflare challenge that refuses a plain download.

The last four rows — ASU, UTRGV, William & Mary and Michigan — arrived with
the 2026-09-12 review, which named Liang Zhan's external collaborators.

**Pitt.** Pitt's schools, departments and centers have no mark of their own.
The four of them on the Collaboration page are therefore one entry carrying the
University's primary lockup — shield and wordmark together — with the units
named beneath it; four cards would otherwise have repeated the same mark four
times.

**Harvard.** Harvard's own sites publish this lockup only in its reversed
colourway — a crimson shield with the wordmark in white, which disappears on a
white card. The 47 white paths in the file are the shield's own detail and the
wordmark's letterforms together, so the wordmark's are the ones this copy sets
to black: every path whose geometry starts beyond x=30, which is where the
shield ends and the lettering begins. Nothing else is touched, and the result
is the positive colourway Harvard publishes elsewhere. Re-downloading the file
means re-applying that change.

Every mark here belongs to the organisation it names, and is shown to identify
a collaboration rather than as an endorsement. Reuse should be confirmed with
each owner before the site goes public — the same condition the members'
portraits carry.
